🎯What is UCP?

The Universal Translator for Commerce

Problem: Every shop has different APIs, payment systems, and processes

Solution: UCP provides a standard language for platforms, businesses, and payment providers

🧱Core Architecture

Core Capabilities

  • ▸ Checkout (cart, tax, totals)
  • ▸ Identity Linking (OAuth 2.0)
  • ▸ Order (webhooks, lifecycle)
  • ▸ Payment Token Exchange

Extensions

  • ▸ Fulfillment (shipping)
  • ▸ Discounts (coupons)
  • ▸ AP2 Mandates (crypto auth)
  • ▸ Custom (vendor-specific)

Transport Layer

  • ▸ REST API (primary)
  • ▸ MCP (LLM tools)
  • ▸ A2A (agent-to-agent)
  • ▸ Embedded (host delegation)

Security

  • ▸ HTTPS, TLS 1.2+
  • ▸ OAuth 2.0, JWS signatures
  • ▸ PCI-DSS compliance
  • ▸ Verifiable credentials

Protocol Flow

End-to-End Transaction

✅Happy Path: Steps 1-3

1. Discovery

Platform → Business: GET /.well-known/ucp

Returns capabilities, services, payment handlers

2. Create Checkout

Platform → Business: POST /checkout-sessions

Send cart items, buyer info, preferences

3. Checkout Response

Business → Platform: Session data

status: ready_for_complete or incomplete or requires_escalation

✅Happy Path: Steps 4-6

4. Token Request

Platform ↔ Credential Provider: Acquire payment token

Platform gets encrypted credential

5. Complete Checkout

Platform → Business: POST /complete with token

Submit encrypted payment_data

6. Order Confirmation

Business → PSP → Platform: Success

status: completed, order ID returned

⚠️Escalation Flow: requires_escalation

When buyer intervention is needed

Business returns status: requires_escalation with continue_url

Error Severities

recoverable Platform can fix via API (e.g., invalid phone format)

requires_buyer_input Need info not available via API (e.g., delivery scheduling)

requires_buyer_review Buyer must authorize (e.g., high-value order, policy compliance)

Platform Actions

1. Resolve any recoverable errors first via Update Checkout

2. Hand off to buyer via continue_url

3. Buyer completes in business UI

4. Platform polls or receives webhook when status: completed
