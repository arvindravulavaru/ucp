UCP

Universal Commerce Protocol

Open standard for commerce interoperability

💡 What is UCP?

An open standard enabling platforms (AI agents, apps), businesses, and payment providers to communicate seamlessly using a standardized common language.

🎯 Four Core Pillars

🔍

Discovery

Autonomous capability negotiation via /.well-known/ucp

🛒

Checkout

Standardized cart, tax calc, payment handler negotiation

💳

Payments

Decoupled token exchange, PCI-DSS compliant patterns

🔐

Security

OAuth 2.0, AP2 mandates, JWS signatures, HTTPS

✨ Key Benefits

  • 🧩 Modular: Mix and match capabilities & extensions
  • 🌐 Transport Agnostic: REST, MCP, A2A, Embedded - choose your protocol
  • 🤖 AI-Ready: Designed for autonomous agents from the ground up
  • 🔓 Open Standard: Apache 2.0 licensed, no vendor lock-in

🎯 Standard Capabilities

  • dev.ucp.shopping.checkout Cart & tax calculation
  • dev.ucp.common.identity_linking OAuth 2.0 user delegation
  • dev.ucp.shopping.order Webhook lifecycle updates
  • dev.ucp.shopping.fulfillment Shipping options (extends checkout)

🔄 Transaction Flow

1. Platform discovers business profile
2. Create checkout session
3. Negotiate payment handlers
4. Acquire payment token from CP
5. Complete checkout with token
6. PSP processes payment
