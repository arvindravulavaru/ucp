1

Platform → Business: Discovery

GET /.well-known/ucp
Platform fetches business profile & capabilities

2

Business → Platform: Profile Response

Profile Response (capabilities, services, payment handlers)
Returns: checkout, payment handlers, extensions

3

Platform → Business: Create Checkout

POST /checkout-sessions (line_items, buyer info)
Platform creates checkout session with cart items

4

Business → Platform: Checkout Response

Checkout Response (totals, payment.handlers[])
Returns: session ID, available payment methods

5

Platform ↔ Credential Provider: Token Request

Payment Token Request
Platform acquires payment token from Credential Provider

6

Credential Provider → Platform: Token Response

Encrypted Token / Network Token
Returns: opaque credential for business

7

Platform → Business: Complete Checkout

POST /checkout-sessions/{id}/complete (payment_data + token)
Platform submits payment credential to complete purchase

8

Business → PSP: Authorize / Capture

Payment authorization and capture
Business processes payment via PSP backend integration

9

Business → Platform: Order Confirmation

Order Confirmation (status: complete)
Returns: order ID, confirmation details
